### Deviations and Remaining Issues

1. **Test names carry no verification IDs.** This follows the binding rule added 2026-10-03 (`.s1mple/S1MPLE.md` Implementation, commit `59dff86`) and the user-approved override of the plan previews. Commit `6fda519` renamed the T2 and T4 tests and replaced a comment citing the parent design file. Run the plan's `-t V<id>` checks by behavior name (map above).
2. **YAML is block style where `${{ }}` appears.** The design's flow mappings (`concurrency: { group: ci-${{ … }} }`, `env: { TAG: ${{ … }} }`, `with: { ref: ${{ env.TAG }} }`) are invalid YAML, because `{` and `}` are flow indicators. The semantics equal §7.
3. **`biome.json` ignores `.s1mple`** in addition to the planned ignores. Biome otherwise lints the parent UI mockup CSS (27 errors). It also uses space indentation, and leaves `rules` out because Biome 2.5 already defaults to recommended rules and deprecates the `recommended` field.
4. **`knip.json` adds `!test/fixtures/boundary-violation/**`** to the design's entries. Without it, knip reports the fixture's deliberately unresolved import, which the interim rule does not allow.
5. **The kernel violation fixture carries `// @ts-nocheck`.** `tsconfig.json` includes `test`, and the fixture's `../lang/markdown/file-type` import must stay unresolvable. This keeps `tsconfig.json` equal to §7.
6. **The boundary scan also catches type-only imports.** `Bun.Transpiler.scanImports` drops `import type` / `export type … from`; tested with and without `trimUnusedImports`. One regex (`TYPE_IMPORT`) adds those specifiers, so a kernel type import from `lang` is reported. Colocated `*.test.ts` files are skipped by V7.1 because they must import `bun:test`. Inline-only `import { type X }` remains invisible to the scan. Preserve these choices.
7. **`LAYER_RULES` encodes:** `app` may also import `package.json` (design `VERSION` reads `pkg.version`); core package policy is a deny-list of runtime (`node:*`, Node builtins, `bun`, `bun:*`) and `@opentui/*`, not an npm allow-list; `kernel` and `filetypes` import no packages at all.
8. **T1's `tsc` check failed on the empty tree** (TS18003, no inputs). It has passed since T2 added the first `.ts` file.
9. **actionlint SC2046 on `publish`** is the design's `gh release create … $([[ "$TAG" == *-* ]] && echo --prerelease) …`. The unquoted substitution is required: quoting would pass an empty argument for non-prerelease tags. Kept as designed; actionlint is not a plan check.
10. **`bun install` warns** `incorrect peer dependency "typescript@7.0.2"`. The source is `bun-ffi-structs` (an `@opentui/core` dependency) declaring `typescript ^5`. It is a warning only; install and frozen install succeed.
11. **Not verifiable locally:** the workflows have not run on GitHub. V15.2, V15.3, and V16.1 (including label availability for `macos-15-intel` and `ubuntu-24.04-arm`) are collected in P3-G1. release-please also needs the repository setting that allows GitHub Actions to create pull requests.
