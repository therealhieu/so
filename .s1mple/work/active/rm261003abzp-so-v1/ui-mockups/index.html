so — vim-modal Markdown editor for the terminal

Seven interactive mockups cover every v1 surface: the app shell, Obsidian-style live preview, the LazyVim-style overlay layer, links and file safety, daily notes and templates, Bases, and the read-only browser preview. Each page simulates the terminal at 120×36 or 80×24 and responds to real keys.

How to review

Click a stateEvery state in the left list jumps straight to that screen, with a caption and the requirement it traces to.
Then use the keyboardClick the terminal and type: j k i Esc :… Press Space and wait for which-key.
Switch viewsViewport 120×36 / 80×24, theme dark / light / NO_COLOR. NO_COLOR shows state using only bold, underline, reverse and glyphs.
OfflineNo network requests: fonts, images, math and diagrams are all local. Content is a realistic sample notes folder.

  • Kanban type value is unverified until checked against a .base file saved by Obsidian 1.14 (REQ7@R2).
  • Extension points: captions marked “Extension point” name the generic areas later features plug into (sign column, window content by editor kind, decoration providers, statusline segments and commands by file type). They are review notes, not product UI (manifest AD5).
